# Summit Rush

A polished, zero-build skiing and snowboarding game made with HTML5 Canvas, CSS and JavaScript. It runs entirely in the browser and is ready for GitHub Pages.

## Play locally

Open `index.html` in a modern browser. No installation or build step is required.

## Controls

- Left / Right arrow or A / D: carve
- Space: jump
- A / D while airborne: spin
- Escape: pause
- On phones and tablets, use the on-screen controls

## Publish with GitHub Pages

1. Create a new public GitHub repository.
2. Upload `index.html`, `style.css`, `game.js`, and this README to the repository root.
3. In the repository, open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Wait around 1–3 minutes. GitHub will show the live website URL on the Pages screen.

## Features

- Ski and snowboard modes
- Procedural endless mountain
- Ramps, tricks, gates, coins, trees and rocks
- Combo scoring, speed, distance and local high score
- Avalanche pressure system
- Keyboard and touch controls
- Responsive design and no external game libraries

Fonts use Google Fonts when online and fall back to the device system font when offline.
